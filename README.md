# VitaCare Pharmacy Website Template

Pages included: Home 1, Home 2 Premium, About, Products, Home Delivery, Case Studies, Contact, Booking Form, 404, Maintenance, Privacy Policy and Terms & Conditions. Case Studies has been removed.

Shared assets: `assets/main.js` and `assets/vitacare-mark.svg` (also used as the favicon).

Brand colors are centralized in CSS root variables: primary teal `--primary: #087F72`, secondary warm gold `--secondary: #D6A84F`. All page styles include 1024px, 768px and 360px responsive breakpoints. Home 2 uses a background video. Lucide provides interface icons and Font Awesome provides footer social icons.

Open `index.html` using VS Code Live Server. External images, video and icon assets require internet access. The booking/contact form is demo-only and does not send or store data; connect a secure backend before publishing. Review privacy and terms wording for your business and applicable law. Do not collect prescription documents or unnecessary sensitive health details through the demo form.
